# Status of the Chapter 0 prototype

This is a **vertical slice**: Chapter 0 („Boarding abgeschlossen"), playable from the title to the
end screen on desktop and phones, plus the Animation Lab. It runs as a static site with no paid
services. This page separates what is real from what is a stand-in.

Legend: ✅ real (the system is done and meant to stay) · 🟡 placeholder (works, will be replaced) ·
🎨 needs authored assets · ❓ open question for the team

## 1. Real and meant to stay ✅

| Area | What exists |
| --- | --- |
| Animation runtime | Skeleton with sheet-space pivots, slots with draw order, keyframed clips (bone channels, parameters, part swaps, z swaps, events), layered animator with cross-fades and additive overlays |
| Locomotion | Distance-driven gait with two-bone IK and fitted strides, so planted feet do not slide (unit-tested); per-character gait flavours |
| Secondary motion | Spring bones (head lag, coat, hat, tank), shape-keeping rope hoses with lag and swing (round loops via cubic rest shapes), tank fluid slosh with bubbles |
| Live vector features | Projected single eyes with lids, saccades, blinks and expression shapes; V-TGM's sphere projection; ICH's letters as a never-mirrored vector layer; LEDs |
| Handedness | Asymmetric details stay on the correct limb when a character turns (used for R-3MI's left arm) |
| Asset pipeline | One SVG rig sheet per character → per-device atlas; an artist's sheet in `art/authored/<id>.svg` replaces the generated one without code changes; the Lab exports the current sheet |
| Cutscenes | Deterministic sequences (setup + timed events): skip lands in the scene's end state, the Lab scrubs them, a test checks that a frame re-simulates pixel-identically; chained clips and prop hand-offs complete inside the simulation step (`onEnd`, `onDone`). Caveat: the trip and avalanche gags start in the game from ICH's current position with the follow camera, so their in-game framing can differ a little from the Lab's re-simulation |
| Game loop | Substeps of at most 1/30 s and game-clock waits: the game keeps real-time pace down to about 10 fps; below that Pixi clamps frame time to 100 ms and the game slows down rather than skipping |
| Cabin and camera | Parallax cabin, night lighting with reading lights, actor tinting by local light, camera with follow, lead, framing and scripted moves |
| Dialogue | Typewriter timing with emphasis, speech bubbles anchored to heads (side placement for tall speakers), captain announcements, choices that cannot be mis-tapped, V-TGM always in English with German subtitles |
| Game systems | Hotspots with markers (always on for touch), magnifier close-ups, case file, HUD, pause and settings, autosave and continue, end screen |
| Audio engine | WebAudio synthesiser behind a gesture gate: ambience, about 25 effects, character babble, music loops, volume and mute |
| Animation Lab | Clips (scrub, slow motion, frame step, skeleton/pivots, onion skin, silhouette, expressions, eye direction), cutscene replay with event markers, character lineup with a height chart; deep links |
| Layout | Desktop, phone landscape and portrait (portrait shows a hint that landscape shows more cabin) |
| Tests | Unit tests (IK, gait, springs, ropes, sequences, atlas packing); Playwright end-to-end: boot, the whole chapter on desktop and as a touch phone, the Lab, determinism, all three ICH designs |

## 2. Placeholder 🟡 (works now, will be replaced)

| Item | Why it is a placeholder |
| --- | --- |
| **All character art** | Generated by code from geometric shapes (`src/characters/*/sheet.ts`). Proportions, colours and key features follow the canon portraits, but the line work and shading are not what an artist would draw. **This is not the final hand-drawn quality.** |
| **All character motion** | Clips are pose-to-pose keyframes typed in code, plus procedural gait and springs. Timing reads, but there are no smears, no drawn squash frames and no hand-keyed overlap. **This is not the final hand-drawn animation quality.** |
| Cabin, props, close-up drawings | Procedural vector art: clean, but without texture and storytelling detail |
| Sound effects, babble voices, music | Synthesised sketches |
| ICH's design | Three directions on one skeleton: A „Das Namensschild" (default), B „Der Aktenschrank", C „Das Periskop". All three play the whole chapter (tested end to end). None is final |
| Sleeping passengers | Anonymous blanket shapes on purpose (see open questions) |

## 4. Canon fidelity notes

- **R-3MI's handedness was corrected to the canon portrait** (it had been mirrored): his left arm carries the
  big shoulder disk with the green ring and the ringed elbow, hangs at the back under the tank, and gets the
  fluid hose from the tank. Tank high and leaning back, exactly three hoses. Checked against the reference by
  independent reviewers; recorded in the character bible as a rule that must not change.
- V-TGM was checked the same way and already matched her portrait.
- Style and proportion details that still differ from R-3MI's portrait (placeholder decisions, listed by the
  same review): the eye sits slightly higher and rounder; the pelvis is light instead of dark graphite; the hip
  caps are simplified; the waist has three fat ribs instead of five thin bars; the legs stand closer together
  than the portrait's A-stance; the torso is a little long (the legs a little short) for the canon proportions.
  Changing the proportions means re-tuning the gait and the seat clips, so it belongs with the authored redraw.
- Canon rules kept everywhere: R-3MI speaks German, V-TGM speaks English with a German subtitle, they use each
  other's designations only, R-3MI is "he", V-TGM is "she". The plane is never shown in the air.

## 6. Known limitations

- **The two slapstick gags are optional.** The seat struggle always plays, but the trip only happens if ICH
  walks over R-3MI's legs and the avalanche only if the player opens bin 15; three clues can be found
  without either (the end screen reports both).

- **ICH B and C use A's clips.** They share the skeleton and every clip, so a few poses were authored for
  A's body: in *nervous*, *brushOff* and *sit* the near glove floats in front of the body (A too); B's far arm
  is mostly hidden behind the wide cabinet; C's telescope pushes the plate into the overhead-bin band during
  *reachUp*; the entrance gag where the coat tail catches in the lavatory door is staged for A's coat, so B's
  folder tabs and C's cape are not caught. Per-design clip overrides are supported (a variant can replace a
  clip by name) once a direction is chosen.

- Software-rendered headless browsers run the game at about 4–5 fps, so game time runs at roughly 0.4× real
  time there and the end-to-end tests take a few minutes (the simulation stays stable). Performance on real
  devices (atlas memory, fill rate, fps) has not been measured yet; the ending's passing shadow uses one blur
  filter.
- Real phones have not been tested yet (only emulated viewports with touch input).
- Accessibility: the game is playable with the keyboard (walk, examine, dialogue, choices; F, M, Esc for the
  case file, sound and menu; Tab moves focus in menus and settings and shows the markers in the cabin), and
  reduced motion is supported; screen-reader support is basic (dialogue is announced, the canvas is not
  described).
